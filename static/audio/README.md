## 推荐的无版权古典音乐资源

### 免费音乐网站
1. **Musopen** (https://musopen.org/)
   - 提供大量无版权古典音乐
   - 高质量录音，可直接下载MP3
   - 推荐：巴赫《空气》、德彪西《月光》、肖邦夜曲

2. **IMSLP** (https://imslp.org/)
   - 国际音乐乐谱图书馆项目
   - 提供公有领域的古典音乐录音
   - 大量巴洛克、古典、浪漫时期作品

3. **Freesound** (https://freesound.org/)
   - 搜索"classical music" + "public domain"
   - 需要注册但免费
   - 质量参差不齐，需要筛选

4. **Internet Archive** (https://archive.org/)
   - 搜索 "classical music" + "public domain"
   - 大量历史录音资源

## 音频质量建议

### 背景音乐设置：
- **比特率**: 192kbps (高质量，清晰度好)
- **声道**: 立体声
- **时长**: 3-8分钟完整乐章
- **文件大小**: 控制在1.5MB以内
- **循环**: 选择自然结尾的完整作品，避免突兀的循环点

### 音效设置：
- **比特率**: 96kbps
- **声道**: 单声道
- **时长**: 0.5-2秒
- **文件大小**: 每个<50KB

### 项目总大小：
- 目标：全部音频文件 < 2MB
- 1个背景音乐(1.5MB) + 2个音效(0.1MB) = 1.6MB ✅

## 版权说明

### 安全的版权选择：
1. **作品年代**: 选择1923年前发表的作品（美国版权法公有领域）
2. **录音版权**: 
   - 优先选择明确标注为公有领域的录音
   - 避免使用现代商业乐团录音
   - 可使用业余音乐家或学生录制的版本

### 推荐策略：
- 使用Musopen等专门提供公有领域音乐的网站
- 选择知名度较高的古典作品（版权状态明确）
- 下载时确认网站明确标注为"Public Domain"

## 压缩步骤

### 背景音乐压缩：
1. 比特率: 192kbps (CBR恒定比特率)
2. 采样率: 44.1kHz
3. 声道: 立体声
4. 格式: MP3
5. 重命名为: `classical-bg.mp3`

### 音效压缩：
1. 比特率: 96kbps
2. 采样率: 44.1kHz
3. 声道: 单声道或立体声
4. 保持原有文件名

## 使用方法

1. 从推荐网站下载合适的古典音乐
2. 使用上述设置压缩为MP3格式
3. 重命名为 `classical-bg.mp3`
4. 放入此文件夹
5. 重新测试小程序功能

## 音量平衡设置

- 背景音乐音量: 0.5 (适中清晰)
- 按键音效音量: 0.2 (不突兀)
- 深呼吸页面音量: 0.3 (放松专注)

这样可以确保古典音乐提供优质的背景氛围，同时保持项目轻量化。
