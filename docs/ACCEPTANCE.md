- [ ] 用户可以正常打开小程序
- [ ] 首页正常显示

## 2. 交互

- [ ] 所有主要按钮可以正常点击

- [ ] 页面没有明显错位

- [ ] 用户可以快速开始练习

- [ ] 不需要注册账号即可使用
- [ ] 练习过程中不会产生不必要的操作负担

- [ ] 连续完成多次练习不会出现异常
- [ ] 页面重复进入不会导致状态错误
